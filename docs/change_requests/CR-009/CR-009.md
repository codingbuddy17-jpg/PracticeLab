## What changes

The **Coding aids** toolbar button now opens a small menu instead of toggling two highlight colours. The menu holds a master switch, then one row per category: colour mark · name · **count** · a checkbox · **‹ ›** to step through that category's hits in reading order.

| Category | On by default | What it marks | Style |
|---|---|---|---|
| Uncertain | yes | probable, likely, suspected, rule out, consistent with… | amber underline |
| Negated / history | yes | no, denies, negative for, ruled out, resolved, history of, s/p… | grey **dashed** underline |
| Linkage | yes | due to, secondary to, associated with, complicated by… | blue underline |
| Query cue | yes | versus/vs, conflicting, unclear, undetermined, "?UTI"… | rose underline |
| Specificity | no | acute, chronic, exacerbation, severity, stage N, type 1/2, with/without complications, initial/subsequent encounter, sequela… | violet underline |
| Site / laterality | no | left, right, bilateral, upper, lower, proximal, distal… | teal underline |
| POA timing | no; **inpatient charts only** | on admission, present on arrival, prior to admission, developed, hospital day N, POD N… | green underline |

- **Quiet by design.** A thin underline with no fill, and the text keeps its colour. The **only** filled highlight is uncertain wording inside a final-diagnosis section (Discharge Diagnoses, Diagnoses, Assessment & Plan, Assessment, Impression, Post-op Diagnosis, Problem List) on an inpatient chart. That's where the inpatient rule applies, so it's bold on a soft amber fill.
- **Setting-aware tooltips.** On IP-DRG, uncertain wording reads "code it as if established if still documented at discharge (Guidelines II.H / III.C)". On every other specialty it reads "do not code as established — code the signs and symptoms (IV.H)". Every category has its own hover explanation.
- **Overlaps resolve once:** the earliest-starting phrase wins, then the longer one. So "complicated by" is linkage and never also specificity, and "VS:" (vital signs) is never read as "versus".
- **Counts match exactly what's drawn**, since they're computed from the same strings the view highlights. A section heading's own title isn't highlighted and isn't counted.
- Choices (master switch and categories) are remembered per reader in the browser. The menu closes on an outside click or **Esc**; Esc no longer closes the whole chart while the menu is open.
- **Never drawn from an answer key**: generic wording only, as before.

## Verified

- **Matching**, probed on sample sentences: "Acute on chronic systolic CHF exacerbation due to…", "Probable … No evidence of PE. History of MI, s/p CABG", "Developed AKI on hospital day 3 … present on admission" (POA cues only on inpatient), "Sepsis vs SIRS, unclear source. ?UTI … complicated by", and "VS: BP…" (not a query cue).
- **Browser** at 1366×900 on a 4-page, 3-document inpatient chart:
  - menu counts equal the drawn marks in every category (uncertain 6, negated 2, linkage 2, specificity 14, site 2);
  - next/previous scrolls to and flashes the hit;
  - only the two final-diagnosis uncertain phrases are bold;
  - outside click and Esc close the menu and leave the chart open;
  - no overflow and no console errors.
